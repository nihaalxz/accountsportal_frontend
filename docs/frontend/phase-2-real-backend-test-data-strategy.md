## Cleanup and Isolation

Since the E2E tests target a local development SQL database instance:

- Tests assert balances relative to the seeded amounts.
- New test transactions generated by E2E writes use unique idempotency keys and distinct description identifiers (`E2E-TEST-...`) to prevent collision.
- The tests do not purge preexisting records to avoid database state corruption between parallel test runners.
